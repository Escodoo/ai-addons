When a chatter AI bridge execution fails, users are left with a stuck
typing indicator and no feedback in the conversation.

This module posts the error in the Discuss channel as the bot user and
clears the typing indicator, extracting a short user-facing message from
the bridge HTTP body (JSON ``detail`` field when available). It works
with any chatter bridge, regardless of the AI runtime behind it.

Usage
=====

Install the module; no configuration is needed.

When a bridge with usage **Chatter** fails (HTTP error or unreachable
service), the bot posts an **AI error** message in the channel with the
detail returned by the service, and the typing indicator is cleared so
the conversation can continue.
