Provisions two **internal** Agno crew bridges:

- Commercial Review → ``POST /bridge/team/commercial-review`` (sales +
  legal)
- Finance Ops → ``POST /bridge/team/finance-ops`` (finance + ops)

These are not Discuss bots and must never be wired to website livechat
or customer support. External personas (``web``, ``support``) stay
single-agent so internal knowledge bases are not exposed.

This bridge targets the companion **Agno service**
(`Escodoo/agno-odoo <https://github.com/Escodoo/agno-odoo>`__).

Configuration
=============

Uses the shared Agno bridge token: ``odoo.conf``
``agno_bridge_auth_token`` or ICP
``ai_agno_internal_teams.bridge_auth_token`` /
``ai_agno_connector.bridge_auth_token``.

URLs (from the Odoo container):

- ``http://agno:8000/bridge/team/commercial-review``
- ``http://agno:8000/bridge/team/finance-ops``

Usage
=====

Call the Agno endpoints from an internal tool or from **Settings →
Technical → AI Bridges** (test execution). Send ``{_odoo, message}``.

Do not add these bridges to website livechat or the support bot. Discuss
personas remain one URL per audience.
