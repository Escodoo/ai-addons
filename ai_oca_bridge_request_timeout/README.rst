Adds a **Request Timeout** field on AI bridges (``ai.bridge``).

The upstream bridge hardcodes a 30s HTTP timeout, which LLM-backed
endpoints routinely exceed. This module lets each bridge configure its
own timeout, leaving bridges without a value on the default behaviour.

**Table of contents**

.. contents::
   :local:

Usage
=====

Set **Request Timeout** (seconds) on the AI bridge form. ``0`` keeps the
default timeout (30s).

An explicit ``timeout`` passed programmatically to ``_execute()`` still
takes precedence over the field.
